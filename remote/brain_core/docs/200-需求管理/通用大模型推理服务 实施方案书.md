### 3.2 backend/schema/ (数据验证层) - **关键更新**
新增 `response_format` (用于强制 JSON) 和 `preset` (用于调用预置的情感分析模板)。

```python
# backend/schema/openai_protocol.py
from pydantic import BaseModel, Field
from typing import List, Optional, Dict, Union

class ChatMessage(BaseModel):
    role: str
    content: str

class ResponseFormat(BaseModel):
    type: str  # e.g., "json_object"

class ChatCompletionRequest(BaseModel):
    model: str
    messages: List[ChatMessage]
    temperature: Optional[float] = 0.7
    max_tokens: Optional[int] = 512
    stream: Optional[bool] = False
    
    # ✅ [新增] 强制模型输出 JSON (情感分析必需)
    response_format: Optional[ResponseFormat] = None
    
    # ✅ [新增] 预置模板 ID (例如 "sentiment_analysis")
    # 这允许客户端只发用户的话，服务器自动加上专家人设
    preset: Optional[str] = None 

class ChatCompletionResponse(BaseModel):
    id: str
    object: str = "chat.completion"
    created: int
    choices: List[dict]
    usage: dict
```

### 3.3 backend/modules/prompt_engine/ (提示词引擎) - **新增模块**
这里定义了**情感分析**的专家逻辑。将业务 Prompt 内置在服务端，减少网络传输，统一标准。

```python
# backend/modules/prompt_engine/registry.py

class PromptRegistry:
    """
    管理预置的 System Prompts
    """
    _PROMPTS = {
        # 🎭 情感分析专家
        "sentiment_analysis": """
你是一个专业的门店服务质量质检员。
请分析用户的对话内容，评估【员工】的情绪状态和服务态度。

请务必输出合法的 JSON 格式，包含以下字段：
1. "sentiment": 情感倾向 (Positive/Neutral/Negative)
2. "aggression_score": 攻击性/急躁指数 (0-10)
3. "empathy_score": 同理心指数 (0-10)
4. "risk_flag": 是否存在冲突风险 (true/false)
5. "reason": 简短的判断理由 (50字以内)

注意：只输出 JSON，不要包含 markdown 代码块或其他废话。
""",
        # 🛡️ 安防监控专家 (预留)
        "security_check": """
你是一个安防监控分析员...
"""
    }

    @classmethod
    def get_system_prompt(cls, preset_id: str) -> str:
        return cls._PROMPTS.get(preset_id)
```

### 3.4 backend/service/ (服务层) - **逻辑升级**
在调用 LLM 之前，先检查是否有 `preset`，如果有，自动注入 System Prompt。

```python
# backend/service/inference_service.py
import uuid
from vllm import SamplingParams
from backend.modules.llm_engine.vllm_runner import VLLMEngineModule
from backend.modules.prompt_engine.registry import PromptRegistry # 新增
from backend.schema.openai_protocol import ChatCompletionRequest, ChatMessage

class InferenceService:
    def __init__(self):
        self.engine = VLLMEngineModule.get_instance()

    async def chat_completion(self, request: ChatCompletionRequest):
        # 1. 处理预置模板 (Preset Handling)
        if request.preset:
            system_content = PromptRegistry.get_system_prompt(request.preset)
            if system_content:
                # 将 System Prompt 插入到消息列表的最前面
                request.messages.insert(0, ChatMessage(role="system", content=system_content))

        # 2. 构造 SamplingParams
        sampling_params = SamplingParams(
            temperature=request.temperature,
            max_tokens=request.max_tokens
        )
        
        # 3. 构造 Prompt (应用 Chat Template)
        # Qwen 模型对 System Prompt 支持很好
        prompt = self._apply_template(request.messages)
        
        # 4. 执行推理
        request_id = f"chat-{uuid.uuid4()}"
        results_generator = self.engine.generate(
            prompt=prompt,
            sampling_params=sampling_params,
            request_id=request_id
        )

        # 5. 获取结果
        final_output = None
        async for request_output in results_generator:
            final_output = request_output

        text_output = final_output.outputs[0].text
        
        # (可选) 如果请求了 JSON 格式，这里可以做简单的校验或清洗
        
        return {
            "id": request_id,
            "choices": [{"message": {"role": "assistant", "content": text_output}}],
            "usage": {
                "prompt_tokens": len(final_output.prompt_token_ids),
                "completion_tokens": len(final_output.outputs[0].token_ids)
            }
        }

    def _apply_template(self, messages):
        # 简易版 Qwen Chat Template
        prompt = ""
        for msg in messages:
            prompt += f"<|im_start|>{msg.role}\n{msg.content}<|im_end|>\n"
        prompt += "<|im_start|>assistant\n"
        return prompt
```

## 4. 如何使用情感分析功能？

完成上述部署后，Project 3 (业务编排) 调用 Project 2 进行情感分析将变得非常简单。

**请求示例 (HTTP POST)**：

```json
POST http://localhost:8000/v1/chat/completions
Header: Authorization: Bearer sk-brain-core-secret
{
    "model": "Qwen2.5-7B",
    "preset": "sentiment_analysis",  // ✨ 魔法字段：自动激活情感分析专家
    "response_format": {"type": "json_object"}, // ✨ 魔法字段：强制 JSON
    "messages": [
        {
            "role": "user", 
            "content": "对话记录：\n顾客：你们这什么破东西！\n员工：先生您别急，坏了就坏了呗，又不是我弄坏的。"
        }
    ]
}
```

**响应示例**：

```json
{
    "id": "chat-...",
    "choices": [
        {
            "message": {
                "role": "assistant",
                "content": "{\"sentiment\": \"Negative\", \"aggression_score\": 8, \"empathy_score\": 1, \"risk_flag\": true, \"reason\": \"员工态度消极且推卸责任，缺乏对顾客情绪的安抚。\"}"
            }
        }
    ]
}
```

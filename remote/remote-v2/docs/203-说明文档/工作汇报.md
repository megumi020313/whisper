## 技术创新点

1. **V3.0多模态对话引擎**: 将声纹识别与ASR深度融合的对话分析系统
2. **V3.1混合模式架构**: 全局VAD门控 + ASR全量处理 + SV优化片段，兼顾效率与召回率
3. **双重Padding机制**: 分离边界判断（100ms）和特征提取（300ms），避免说话人归属错误
4. **三级容忍度过滤**: 中心点 → IoU ≥ 30% → 边界±100ms，给ASR更多信任
5. **IoU三级对齐**: IoU优先 → Center次之 → Score兜底，提升词-说话人对齐准确率
6. **S-Norm对称归一化**: 注册时预计算T-Norm参数，实现识别时零开销的精度优化
7. **V3.3动态梯度边界校正**: 基于位置感知的智能边界修正算法
8. **V3.4三明治平滑法则**: 基于时长的A-B-A结构智能修正机制
9. **并行感知架构**: 声纹+ASR并行处理，有效减少整体延迟

## 1. 项目概述

### 1.1 项目名称

火锅店固定员工专属 AI 降噪声纹锁麦克风开发

### 1.2 核心目标

通过「AI 降噪 + 声纹识别」双模块协同，实现精准声纹识别与实时降噪功能，适用于火锅店等嘈杂环境。系统仅收录固定员工声音，过滤环境杂讯和非目标员工声音，保障员工人声清晰可辨，总延迟≤25ms，支持树莓派5边缘部署。

### 1.3 项目背景

火锅店环境噪声复杂（多源动态混合），传统麦克风无法区分「固定员工人声」「其他员工人声」与「环境噪声」，导致收录信息混乱。本项目针对「仅采集固定员工指令」需求，结合轻量声纹识别与 AI 降噪技术，在低成本硬件上实现精准人声锁定，适配后厨传菜、前厅点餐等工作场景。

### 1.4 技术架构

**整体架构**：基于树莓派5的边缘计算架构，采用模块化设计，实现音频采集、降噪处理、声纹识别、决策输出四大核心功能。

**核心技术栈**：
- 深度学习框架：PyTorch、SpeechBrain
- 音频处理：librosa、soundfile
- 模型部署：ONNX Runtime
- 硬件平台：树莓派5

**模块关系**：
```
音频采集 → 降噪处理 → 声纹识别 → 决策输出
       ↓          ↓          ↓          ↓
   数据预处理   特征提取    模板匹配    音频输出
```

## 6. 核心技术模块设计

### 6.1 音频采集模块

**功能描述**：负责从 USB 麦克风采集原始音频数据，进行格式转换和初步处理，为后续模块提供标准化音频流。

**核心需求**：
- 支持 16kHz/16bit/单声道音频采集
- 实时音频流处理，低延迟
- 音频帧缓冲管理
- 设备热插拔支持

**模块架构**：
```
麦克风设备 → 音频驱动 → 音频流管理 → 帧缓冲 → 输出标准化音频帧
```

**核心函数**：
- `audio_capture_init()`：初始化音频采集设备
- `audio_stream_start()`：启动音频流
- `read_audio_frame()`：读取音频帧
- `audio_stream_stop()`：停止音频流
- `audio_capture_release()`：释放音频设备资源

**配置参数**：
- 采样率：16000Hz
- 位深：16bit
- 声道数：1
- 帧大小：160 samples（10ms）

### 6.2 降噪处理模块

**功能描述**：基于 RNNoise-Lite 架构，实现实时音频降噪，降低环境噪声对后续声纹识别的影响。

**核心需求**：
- 实时降噪处理，延迟≤15ms
- 噪声衰减≥30dB
- 人声失真率≤5%
- 支持动态降噪强度调整
- 模型轻量化，适合边缘部署

**模块架构**：
```
输入音频帧 → 特征提取（STFT）→ 噪声估计 → 掩码生成 → 频谱恢复 → 输出降噪音频帧
```

**核心函数**：
- `rnnoise_model_init()`：初始化降噪模型
- `extract_noise_features()`：提取噪声特征
- `denoise_audio_frame()`：处理单帧音频降噪
- `update_noise_profile()`：更新噪声 profile
- `rnnoise_model_release()`：释放降噪模型资源

**配置参数**：
- STFT 窗口大小：512
- STFT 跳跃大小：256
- 特征维度：65维对数幅度谱
- 模型类型：3层GRU（384维）

### 6.3 声纹识别模块

**功能描述**：基于 SpeechBrain ECAPA-TDNN 模型，实现员工身份识别，拒绝非目标员工。

**核心需求**：
- 声纹识别准确率≥98%（≤20人）
- 识别延迟≤5ms
- 支持说话人嵌入向量提取
- 支持模板匹配和相似度计算
- 支持动态阈值调整

**模块架构**：
```
输入音频帧 → 特征提取 → 说话人嵌入 → 模板匹配 → 相似度计算 → 输出识别结果
```

**核心函数**：
- `speaker_model_init()`：初始化声纹识别模型
- `extract_speaker_embedding()`：提取说话人嵌入向量
- `compute_similarity()`：计算相似度
- `match_speaker()`：匹配说话人
- `generate_speaker_template()`：生成说话人模板
- `speaker_model_release()`：释放声纹模型资源

**配置参数**：
- 嵌入维度：192维
- 相似度阈值：动态调整（0.92-0.98）
- 模型类型：ECAPA-TDNN
- 损失函数：Contrastive Loss

### 6.4 决策与输出模块

**功能描述**：根据声纹识别结果和降噪音频，进行决策判断，输出最终音频。

**核心需求**：
- 基于相似度阈值的决策判断
- 支持静音输出（非目标员工）
- 支持音频帧缓冲管理
- 实时输出，延迟≤5ms

**模块架构**：
```
声纹识别结果 → 决策判断 → 音频帧选择 → 输出缓冲 → 音频输出
```

**核心函数**：
- `decision_making()`：决策判断
- `select_audio_frame()`：选择输出音频帧
- `output_audio_frame()`：输出音频帧
- `reset_output_buffer()`：重置输出缓冲

**配置参数**：
- 决策延迟：≤5ms
- 输出缓冲大小：4帧

### 6.5 系统管理模块

**功能描述**：负责系统配置管理、状态监控、日志记录和异常处理。

**核心需求**：
- 支持 YAML 配置文件
- 实时系统状态监控
- 结构化日志记录
- 异常处理和自动恢复
- 声纹模板管理

**模块架构**：
```
配置文件 → 配置加载 → 系统初始化 → 状态监控 → 日志记录 → 异常处理
```

**核心函数**：
- `load_config()`：加载配置文件
- `init_system()`：初始化系统
- `monitor_system_status()`：监控系统状态
- `log_system_event()`：记录系统事件
- `handle_exception()`：处理异常
- `manage_speaker_templates()`：管理声纹模板

**配置参数**：
- 配置文件格式：YAML
- 日志级别：INFO
- 监控频率：1Hz

## 1. 项目概述

### 1.1 项目目标

基于双Tesla V100 GPU服务器，构建高性能、抗噪的声纹识别后端系统，服务于火锅店等嘈杂环境。
- **核心指标**: 
  - 识别准确率: 99%+ (基于向量匹配)
  - 端到端延迟: < 200ms (含网络传输)
- **业务流程**: 硬件采集音频 → HTTP上传 → 服务器VAD检测 → 声纹特征提取 → 向量库匹配 → 返回结果。
- **注册机制**: 采用**特征向量注册**（One-shot Registration）。录入即用，无需训练。
- **微调机制**: 仅用于**领域自适应**（Domain Adaptation），利用火锅店环境音优化模型底座，非日常操作。

### 1.2 技术栈

- **语言**: Python 3.10+
- **深度学习框架**: PyTorch
- **核心模型库**: ModelScope / 3D-Speaker / Silero VAD
- **Web框架**: FastAPI (推荐) 或 Flask + Gunicorn (多Worker模式)
- **数据存储**: JSON/Pickle (MVP阶段) -> Redis/Milvus (进阶阶段) 用于存储声纹库

## 5. 详细需求拆分

### 需求 1: 预处理模块 (VAD)
**优先级**: P0

*   **1.1 VAD 集成**:
    *   集成 Silero VAD 模型。
    *   **路径**: 模型文件存放在 `remote/models/vad/`。
    *   功能：输入音频，输出是否存在人声。若无人声，直接返回，不调用声纹模型。

### 需求 2: 核心声纹模型 (ERes2NetV2)
**优先级**: P0

*   **2.1 模型封装**:
    *   实现 `ERes2NetV2` 类。
    *   **路径**: 强制加载 `remote/models/eres2netv2/` 下的 `pytorch_model.bin` 和配置文件。
    *   实现 `extract_embedding(audio)` 方法，输出归一化的 192维向量。
*   **2.2 版本控制**:
    *   代码中通过加载本地绝对路径的方式，彻底解决 ModelScope 版本依赖问题。

### 需求 3: 向量存储与匹配 (注册/识别)
**优先级**: P0

*   **3.1 向量存储 (`vector_storage.py`)**:
    *   实现内存级数据库。
    *   **持久化**: 定期将内存数据保存到 `remote/data/vector_db/users.json`。
    *   `register(user_id, embedding)`: 存入/更新用户向量。
*   **3.2 匹配逻辑**:
    *   `identify(embedding, threshold=0.35)`: 计算余弦相似度，返回最高分用户。

### 需求 4: API 服务
**优先级**: P0

*   **4.1 接口定义**:
    *   `POST /api/v1/register`: 上传音频 + UserID。音频可选择保存至 `data/audio_samples/` 用于后续优化。
    *   `POST /api/v1/recognize`: 上传音频，执行 VAD -> 识别逻辑。
*   **4.2 协议优化**:
    *   使用 `multipart/form-data` 传输 `.wav` 文件。

## 6. 双GPU利用策略

为了充分利用双 Tesla V100，避免资源浪费，采用 **多进程 Worker 绑定** 策略。

### 6.1 部署架构
使用 `Gunicorn` 作为进程管理器，`Uvicorn` 作为 Worker 类。

### 6.2 启动脚本 (`scripts/run_server.sh`)
```bash
# 示例逻辑
# 启动 2 个 Worker，分别绑定到 GPU 0 和 GPU 1
export CUDA_VISIBLE_DEVICES=0,1
gunicorn -w 2 -k uvicorn.workers.UvicornWorker src.api.app:app --bind 0.0.0.0:8000
```

### 6.3 代码适配
在 `src/core/config.py` 中：
*   Worker 1 初始化时，加载 `models/` 下的模型到 `cuda:0`。
*   Worker 2 初始化时，加载 `models/` 下的模型到 `cuda:1`。

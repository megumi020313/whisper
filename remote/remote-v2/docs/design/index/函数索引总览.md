#### <a name="load_audio"></a>load_audio

**功能**: 加载音频文件

**签名**:
```python
def load_audio(
    audio_path: Union[str, Path],
    sample_rate: int = 16000,
    mono: bool = True
) -> Tuple[np.ndarray, int]
```

**参数**:
- `audio_path`: 音频文件路径
- `sample_rate`: 目标采样率，默认16000
- `mono`: 是否转换为单声道，默认True

**返回**: `(audio_data, sample_rate)` 元组

**使用示例**:
```python
from src.utils.audio_utils import load_audio

audio, sr = load_audio("test.wav", sample_rate=16000)
```

**文件位置**: `src/utils/audio_utils.py:90-120`

#### <a name="calculate_diarization_intervals"></a>calculate_diarization_intervals

**功能**: V12.0多人全库识别 + 网格投票算法

**签名**:
```python
def calculate_diarization_intervals(
    raw_segments: List[Dict[str, Any]],
    total_duration: float,
    stride: float = 0.1,
    max_silence_gap: float = 15.0,
    identification_threshold: float = 1.8
) -> List[Dict[str, Any]]
```

**参数**:
- `raw_segments`: 原始片段列表（包含start/end/user/score）
- `total_duration`: 音频总时长（秒）
- `stride`: 时间分辨率（秒），默认0.1
- `max_silence_gap`: 最大静音间隙（秒）
- `identification_threshold`: 识别阈值（Z-Score）

**返回**: 说话人分段列表

**核心算法**: 网格投票 + 强力平滑 + 片段合并

**文件位置**: `src/utils/audio_utils.py:642-800`

**详细文档**: `docs/V12.0.md`

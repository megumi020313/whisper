# SMP 项目迁移方案

## 迁移目标

将 `smp/code/software/` 下的**声纹识别相关**代码迁移到 `SMP/` 目录，按照模块划分规范重新组织，并确保：
1. 不破坏SMP的文件夹结构
2. 不迁移前端代码
3. **只迁移声纹识别相关功能，不迁移降噪和部署相关部分**
4. 迁移后功能正常使用
5. 迁移后移动文件夹也能正常使用（使用绝对路径）
6. 符合导入路径规范和函数规范

## 迁移范围说明

### ✅ 迁移的内容（声纹识别相关）

- **Web服务**：Flask应用（声纹识别API）
- **核心模块**：validators, exceptions, error_handler, buffers
- **声纹训练**：train_speaker.py, add_speaker_template.py, process_speaker_audio.py
- **声纹识别包装器**：speaker_id_wrapper.py（从deployment/）
- **声纹测试**：test_speaker.py
- **声纹配置**：speaker_id_config.yaml
- **声纹模型**：speechbrain_model_*（训练好的模型）
- **声纹文档**：声纹识别训练流程详解.md

### ❌ 不迁移的内容（降噪和部署相关）

- **降噪相关**：
  - train_noise.py
  - rnnoise_model.py
  - rnnoise_wrapper.py
  - process_noise_audio.py
  - rnnoise_config.yaml
  - rnnoise_model_*（训练好的降噪模型）
  - 降噪模型训练流程详解.md
  - test_noise.py

- **部署相关**：
  - deployment/ 目录下的所有文件（除了 speaker_id_wrapper.py）
  - deployment/*.ps1, *.sh（部署脚本）
  - deployment/utils/model_loader.py
  - deployment/main_deployment.py
  - deployment/monitor_*.py
  - deployment/test_model_load.py

- **统一训练**：
  - train_unified_model.py（包含降噪训练）
  - merge_data.py（可能包含降噪数据）

## 目标结构映射

### 1. Web服务层 → backend/api/

**迁移内容**：
- `web/app.py` → `backend/api/app.py`
- `web/config.py` → `backend/config/web_config.py`
- `web/utils/audio_validator.py` → `backend/utils/audio_validator.py`
- `web/utils/audio_storage.py` → `backend/utils/audio_storage.py`

**说明**：
- Flask应用作为API层，放在 `backend/api/`
- Web配置放在 `backend/config/`
- Web工具函数是纯工具函数，放在 `backend/utils/`

### 2. 核心模块 → backend/core/

**迁移内容**：
- `core/validators.py` → `backend/core/validators.py`
- `core/exceptions.py` → `backend/core/exceptions.py`
- `core/error_handler.py` → `backend/core/error_handler.py`
- `core/buffers.py` → `backend/core/buffers.py`

**说明**：
- 核心业务逻辑模块，保持原有结构

### 3. 声纹识别模块 → backend/modules/speaker_id/

**迁移内容**：
- `deployment/speaker_id_wrapper.py` → `backend/modules/speaker_id/speaker_id_wrapper.py`

**说明**：
- 声纹识别包装器是完整业务功能，放在 `backend/modules/speaker_id/`
- 不迁移降噪包装器和部署脚本

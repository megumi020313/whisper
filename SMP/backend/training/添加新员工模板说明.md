# 添加新员工模板使用说明

## 功能说明

`add_speaker_template.py` 是一个独立的脚本，用于将新员工的音频数据转换为声纹模板，并自动添加到现有的 `speaker_embeddings.json` 文件中。

## 使用方法

### 1. 基本用法

#### 添加单个音频文件

```bash
python add_speaker_template.py \
    --speaker-id emp_003 \
    --audio new_employee.wav
```

#### 添加文件夹中的所有音频文件（推荐）

```bash
python add_speaker_template.py \
    --speaker-id emp_003 \
    --audio-dir new_employee_recordings/
```

脚本会自动递归查找文件夹中的所有 `.wav` 文件。

### 2. 指定模型文件路径

如果不指定 `--model` 参数，脚本会自动查找最新的 `speaker_embeddings.json` 文件。

如果需要指定特定的模型文件：

```bash
python add_speaker_template.py \
    --speaker-id emp_003 \
    --audio-dir recordings/ \
    --model models/speechbrain_model_20251209_195443/speaker_embeddings.json
```

### 3. 完整参数示例

```bash
python add_speaker_template.py \
    --speaker-id emp_003 \
    --audio-dir new_employee_recordings/ \
    --model models/speechbrain_model_XXX/speaker_embeddings.json \
    --encoder-root model/speechbrain \
    --sample-rate 16000 \
    --device cpu
```

## 参数说明

| 参数 | 必需 | 说明 |
|------|------|------|
| `--speaker-id` | ✅ | 新员工ID（如 `emp_003`） |
| `--audio` | ✅* | 单个音频文件路径 |
| `--audio-dir` | ✅* | 包含音频文件的文件夹路径 |
| `--model` | ❌ | `speaker_embeddings.json` 文件路径（不指定则自动查找最新的） |
| `--encoder-root` | ❌ | SpeechBrain encoder路径（默认: `model/speechbrain`） |
| `--sample-rate` | ❌ | 采样率（默认: 16000） |
| `--device` | ❌ | 设备：`cpu` 或 `cuda`（默认: `cpu`） |

*注：`--audio` 和 `--audio-dir` 必须指定其中一个

## 音频要求

### 格式要求
- **格式**: WAV
- **采样率**: 16kHz（脚本会自动重采样）
- **位深**: 16bit
- **声道**: 单声道（脚本会自动转换）

### 数量要求
- **最少**: 3-5个音频文件
- **推荐**: 10-20个音频文件
- **每个文件时长**: 10-20秒

### 质量要求
- 清晰，包含语音内容
- 建议在真实场景（火锅店）录制
- 包含不同说话内容、情绪、音量变化

## 工作流程

1. **加载现有模板**: 从 `speaker_embeddings.json` 加载所有现有员工模板
2. **加载encoder**: 加载训练好的SpeechBrain encoder
3. **提取嵌入向量**: 从新员工的每个音频文件提取嵌入向量
4. **计算模板**: 计算所有嵌入向量的平均值作为新员工模板
5. **保存模板**: 将新员工模板添加到 `speaker_embeddings.json` 并保存

## 示例场景

### 场景1：添加单个新员工

```bash
# 新员工 emp_003 的录音在 recordings/emp_003/ 文件夹中
python add_speaker_template.py \
    --speaker-id emp_003 \
    --audio-dir recordings/emp_003/
```

### 场景2：批量添加多个员工

```bash
# 假设有多个新员工，每个员工一个文件夹
for emp_id in emp_003 emp_004 emp_005; do
    python add_speaker_template.py \
        --speaker-id $emp_id \
        --audio-dir recordings/$emp_id/
done
```

### 场景3：从单个音频文件添加

```bash
# 如果只有一个音频文件
python add_speaker_template.py \
    --speaker-id emp_003 \
    --audio recordings/emp_003_single.wav
```

## 注意事项

1. **员工ID格式**: 建议使用 `emp_XXX` 格式（如 `emp_003`），与现有员工保持一致
2. **覆盖确认**: 如果员工ID已存在，脚本会询问是否覆盖
3. **自动查找模型**: 如果不指定 `--model`，脚本会自动查找最新的模型文件
4. **错误处理**: 如果某个音频文件处理失败，脚本会跳过并继续处理其他文件

## 常见问题

### Q: 需要重新训练模型吗？
A: **不需要**。使用对比损失训练后，模型已经学会了提取声纹特征。新增员工只需添加模板即可。

### Q: 音频文件需要预处理吗？
A: **不需要**。脚本会自动处理：
- 自动转换为单声道
- 自动重采样到16kHz
- 自动提取嵌入向量

### Q: 可以添加多少个员工？
A: **理论上无限制**。但建议：
- 每个员工至少3-5个音频文件
- 模板文件大小会随着员工数量增加而增加

### Q: 如果添加失败怎么办？
A: 检查：
1. 音频文件格式是否正确（WAV格式）
2. 音频文件是否包含有效语音内容
3. 模型文件路径是否正确
4. encoder文件是否完整

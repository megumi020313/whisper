## 数据构成

### 数据来源

- **目标员工音频**: `raw_data/speaker/data/emp_XXX/` 目录下的WAV文件
- **负样本音频**: `raw_data/speaker/VCTK/` 目录下的WAV文件（用于训练，不保存模板）

### 数据格式要求

- **采样率**: 16kHz
- **位深**: 16bit
- **声道**: 单声道
- **文件命名**: `emp_XXX_YY.wav` 或 `pXXX_YY.wav`
- **每段时长**: 10-20秒
- **每人样本数**: 至少5个，最多50个（负样本限制）

### 数据组织结构

```
raw_data/speaker/
  ├── data/
  │   ├── emp_001/
  │   │   ├── emp_001_01.wav
  │   │   ├── emp_001_02.wav
  │   │   └── ...
  │   └── emp_002/
  │       ├── emp_002_01.wav
  │       └── ...
  └── VCTK/
      ├── p226/
      │   ├── p226_001.wav
      │   └── ...
      └── ...
```

### 样本数量限制逻辑

- **目标员工** (`emp_*`): 不限制，使用所有样本
- **负样本** (VCTK等): 限制到50个样本/人（平衡数据集）
- **目的**: 避免负样本过多导致模型偏向负样本

## 训练阶段

### 流程图

```
加载配置文件
    ↓
样本收集
    ├─ 递归搜索WAV文件
    ├─ 提取说话人ID
    ├─ 按说话人分组
    └─ 应用样本数量限制
    ↓
数据划分
    ├─ 训练集 (80%)
    └─ 验证集 (20%)
    ↓
数据加载与增强
    ├─ 时域增强（噪声、语速、音量、时间偏移、混响）
    └─ 频域增强（SpecAugment）
    ↓
模型初始化
    ├─ 加载SpeechBrain ECAPA-TDNN
    ├─ 冻结底层参数
    └─ 解冻高层层
    ↓
训练循环
    ├─ 前向传播（提取192维嵌入）
    ├─ 损失计算（Contrastive/Triplet/Softmax）
    ├─ 反向传播（FP16 + 梯度累积）
    ├─ 优化器更新
    └─ 验证评估
    ↓
早停判断
    ├─ 多指标综合评估
    └─ 保存最佳模型
    ↓
模板生成
    ├─ 提取所有样本嵌入向量
    ├─ 计算平均模板
    └─ 过滤并保存目标员工模板
    ↓
模型校准
    ├─ 计算相似度统计
    └─ 推荐最优阈值
    ↓
模型导出
    ├─ 保存PyTorch检查点
    ├─ 导出ONNX模型
    └─ 生成可视化报告
```

### 训练逻辑

#### 1. 样本收集

- 从 `raw_data/speaker/` 递归搜索所有WAV文件
- 从文件名提取说话人ID（`emp_XXX_YY.wav` → `emp_XXX`）
- 按说话人分组
- 应用样本数量限制：只限制负样本，目标员工不限制

#### 2. 数据加载

- 创建 `SpeakerDataset` 类
- 训练时启用数据增强（8种策略）
- 验证时不启用数据增强
- 创建DataLoader（batch_size=16，多进程加载）

#### 3. 模型微调

- 加载SpeechBrain ECAPA-TDNN预训练模型
- 冻结底层参数，只训练高层层
- 使用Contrastive Loss（支持拒绝非目标员工）
- 优化器：AdamW，学习率：6e-5
- 学习率调度：Cosine退火（带预热）

#### 4. 训练循环

每个Epoch：
1. 前向传播：提取192维嵌入向量
2. 损失计算：根据损失函数类型计算
3. 反向传播：混合精度(FP16) + 梯度累积(2步) + 梯度裁剪
4. 优化器更新：每2个累积步更新一次
5. 验证评估：在验证集上计算损失和准确率

#### 5. 早停机制

- 多指标早停：综合验证准确率和F1
- 耐心值：10个epoch
- 自动保存最佳模型

#### 6. 模板生成

- 对每个说话人的所有样本提取嵌入向量
- 计算平均模板（192维向量）
- 只保存目标员工模板（`emp_*`），过滤VCTK等负样本
- 保存为JSON格式：`speaker_embeddings.json`

#### 7. 模型校准

- 在训练样本上计算相似度
- 计算统计信息（最小/平均/最大相似度）
- 推荐最优阈值：`max(0.75, min(min_sim - 0.02, 0.99))`

#### 8. 模型导出

- 保存PyTorch检查点：`fine_tuned_embedding_model.pt`
- 导出ONNX模型：`speaker_model.onnx`
- 生成可视化：训练曲线、混淆矩阵、t-SNE图

## 测试阶段

### 流程图

```
加载模型
    ├─ speaker_embeddings.json（说话人模板）
    └─ SpeechBrain encoder
    ↓
加载测试数据
    ├─ 从测试目录读取WAV文件
    └─ 文件名格式：emp_XXX_test.wav
    ↓
提取测试音频嵌入
    ├─ 格式转换（16kHz/单声道）
    └─ 使用encoder提取192维嵌入
    ↓
相似度计算
    ├─ 与所有模板计算余弦相似度
    └─ 选择最高相似度
    ↓
识别判断
    ├─ 相似度 >= 阈值 → 识别成功
    └─ 相似度 < 阈值 → 识别失败
    ↓
生成测试报告
    ├─ 准确率统计
    ├─ 错误样本列表
    └─ JSON测试报告
```

### 测试逻辑

#### 1. 模型加载

- 加载 `speaker_embeddings.json`（包含所有目标员工的192维模板）
- 加载SpeechBrain encoder（用于提取测试音频嵌入）

#### 2. 测试数据加载

- 从测试目录读取WAV文件
- 文件名格式：`emp_XXX_test.wav`
- 从文件名提取真实说话人ID

#### 3. 识别流程

1. **提取嵌入向量**:
   - 对测试音频进行格式转换（16kHz/单声道）
   - 使用encoder提取192维嵌入向量

2. **相似度计算**:
   - 与所有模板计算余弦相似度
   - 选择最高相似度及其对应的说话人ID

3. **识别判断**:
   - 如果最高相似度 >= 阈值 → 识别为该说话人
   - 如果最高相似度 < 阈值 → 识别失败（拒绝）

#### 4. 评估指标

- **准确率**: 正确识别的样本数 / 总样本数
- **目标准确率**（根据说话人数量）:
  - ≤20人: 98%
  - ≤100人: 96%
  - >100人: 95%

#### 5. 测试报告

- 生成JSON格式测试报告
- 包含：准确率、错误样本列表、每个样本的详细结果

## 推理阶段

### 流程图

```
加载模型
    ├─ speaker_embeddings.json（说话人模板）
    └─ SpeechBrain encoder
    ↓
接收音频输入
    ├─ 实时音频流
    └─ 或音频文件
    ↓
音频预处理
    ├─ 格式转换（16kHz/单声道）
    └─ 音频分段（可选）
    ↓
提取嵌入向量
    └─ 使用encoder提取192维嵌入
    ↓
相似度计算
    ├─ 与所有模板计算余弦相似度
    └─ 选择最高相似度
    ↓
识别结果
    ├─ 相似度 >= 阈值 → 返回说话人ID
    └─ 相似度 < 阈值 → 返回"unknown"或拒绝
```

### 推理逻辑

#### 1. 模型加载

- 加载 `speaker_embeddings.json`（说话人模板库）
- 加载SpeechBrain encoder（嵌入提取器）
- 加载识别阈值（从校准报告获取推荐值）

#### 2. 音频输入

- **实时音频流**: 从麦克风或音频设备接收
- **音频文件**: 从文件系统读取WAV文件
- **格式要求**: 16kHz/16bit/单声道

#### 3. 音频预处理

- 格式转换：确保采样率为16kHz，单声道
- 音频分段（可选）：如果音频过长，可以分段处理
- 静音检测（可选）：去除前后静音

#### 4. 嵌入提取

- 使用SpeechBrain encoder提取192维嵌入向量
- 输入：音频波形（1D数组）
- 输出：192维嵌入向量

#### 5. 相似度匹配

- 与所有模板计算余弦相似度
- 公式：`similarity = dot(embedding, template) / (norm(embedding) * norm(template))`
- 选择最高相似度及其对应的说话人ID

#### 6. 识别决策

- **识别成功**: 最高相似度 >= 阈值 → 返回说话人ID（如 `emp_001`）
- **识别失败**: 最高相似度 < 阈值 → 返回 `unknown` 或拒绝

#### 7. 输出结果

- **说话人ID**: 识别到的员工ID（如 `emp_001`）
- **相似度**: 匹配的相似度分数（0-1之间）
- **置信度**: 基于相似度的置信度评估

### 推理优化

- **批量处理**: 可以批量处理多个音频，提高效率
- **缓存机制**: 模板向量可以预先加载到内存
- **阈值调整**: 可以根据实际场景调整识别阈值
- **拒绝策略**: 对于相似度低于阈值的情况，可以返回"unknown"或直接拒绝

## 总结

### 数据构成

- 目标员工音频 + 负样本音频（VCTK）
- 样本数量限制：只限制负样本，目标员工不限制

### 训练阶段

- 样本收集 → 数据划分 → 数据增强 → 模型微调 → 模板生成 → 模型导出
- 使用Contrastive Loss，支持拒绝非目标员工
- 冻结底层，只训练高层

### 测试阶段

- 加载模型 → 提取测试音频嵌入 → 相似度计算 → 识别判断 → 生成报告
- 目标准确率：≤20人98%，≤100人96%，>100人95%

### 推理阶段

- 加载模型 → 音频预处理 → 提取嵌入 → 相似度匹配 → 识别决策
- 支持实时音频流和音频文件
- 可配置阈值和拒绝策略

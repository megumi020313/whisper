# 固定员工专属AI降噪声纹锁麦克风 - 配置文件参数说明书

## 1. 配置文件概述

本项目使用YAML格式的配置文件，分为**训练阶段配置**和**部署阶段配置**两大类，用于控制模型训练过程和实时音频处理流程。所有配置文件均采用层次化结构，便于理解和维护。

## 2. 训练阶段配置文件

### 2.1 降噪模型训练配置 (`software/training/config/rnnoise_config.yaml`)

#### 功能说明
用于配置RNNoise-Lite降噪模型的训练参数，针对火锅店环境噪声进行定向优化。

#### 参数说明

### `model`

#### `pretrained_path`
- **类型**：字符串
- **默认值**：`model/rnnoise/rnnoise8Za_25.pth`
- **说明**：预训练降噪模型路径

#### `base_output_dir`
- **类型**：字符串
- **默认值**：`models`
- **说明**：训练后模型保存的基础目录

### `training`

#### `dataset_path`
- **类型**：字符串
- **默认值**：`data/noise_processed.wav`
- **说明**：预处理后的噪声数据集路径

#### `raw_dataset_path`
- **类型**：字符串
- **默认值**：`raw_data/noise`
- **说明**：原始噪声文件目录

#### `noise_type`
- **类型**：字符串
- **默认值**：`hotpot_restaurant`
- **说明**：噪声类型描述（用于模型标识）

#### `noise_source`
- **类型**：字符串
- **默认值**：`auto`
- **说明**：噪声源类型：`auto`(自动选择)、`processed`(已处理)、`raw`(原始)

#### `profile`
- **类型**：字符串
- **默认值**：`noisy`
- **说明**：噪声环境配置：`noisy`(高噪)、`general`(通用)、`quiet`(安静)

#### `adaptation_mode`
- **类型**：字符串
- **默认值**：`micro_tune`
- **说明**：适配模式：`from_scratch`(从头训练)、`micro_tune`(微调)、`profile_only`(仅生成配置)

#### `profile_report`
- **类型**：字符串
- **默认值**：`models/noise_profile.json`
- **说明**：噪声分析报告输出路径

#### `epochs`
- **类型**：整数
- **默认值**：`3`
- **说明**：训练轮数

#### `batch_size`
- **类型**：整数
- **默认值**：`2`
- **说明**：批量大小（受硬件内存限制）

#### `learning_rate`
- **类型**：浮点数
- **默认值**：`3e-4`
- **说明**：学习率

#### `sequence_length`
- **类型**：整数
- **默认值**：`64`
- **说明**：训练序列长度

#### `window_size`
- **类型**：整数
- **默认值**：`512`
- **说明**：音频分析窗口大小

#### `hop_length`
- **类型**：整数
- **默认值**：`256`
- **说明**：窗口移动步长

#### `feature_bins`
- **类型**：整数
- **默认值**：`65`
- **说明**：特征频带数量

#### `model_suffix`
- **类型**：字符串
- **默认值**：`_custom`
- **说明**：自定义模型后缀

### `validation`

#### `noise_reduction_target`
- **类型**：整数
- **默认值**：`25`
- **说明**：目标噪声衰减值(dB)

#### `distortion_target`
- **类型**：整数
- **默认值**：`5`
- **说明**：目标人声失真率(%)

#### 配置建议
- 若噪声环境变化较大，建议使用`adaptation_mode: from_scratch`从头训练
- 微调时可将`epochs`设置为3-5轮，避免过拟合
- 噪声衰减目标建议设置为25-30dB，平衡降噪效果和语音质量

### 2.2 声纹模型训练配置 (`software/training/config/speaker_id_config.yaml`)

#### 功能说明
用于配置SpeechBrain ECAPA-TDNN声纹识别模型的训练参数，实现目标员工的精准识别。

#### 参数说明

### `model`

#### `pretrained_path`
- **类型**：字符串
- **默认值**：`../model/speechbrain/embedding_model.ckpt`
- **说明**：预训练声纹模型路径

#### `encoder_root`
- **类型**：字符串
- **默认值**：`../model/speechbrain`
- **说明**：模型编码器根目录

#### `base_output_dir`
- **类型**：字符串
- **默认值**：`../models`
- **说明**：训练后模型保存目录

#### `freeze_layers`
- **类型**：布尔值
- **默认值**：`true`
- **说明**：是否冻结底层模型参数（建议设为true）

#### `unfreeze_layers`
- **类型**：列表
- **默认值**：`["fc"]`
- **说明**：需要解冻训练的层（通常为全连接层）

#### `skip_onnx_export`
- **类型**：布尔值
- **默认值**：`false`
- **说明**：是否跳过ONNX模型导出（建议设为false）

### `training`

#### `dataset_path`
- **类型**：字符串
- **默认值**：`../raw_data/speaker`
- **说明**：说话人音频数据集目录

#### `sample_rate`
- **类型**：整数
- **默认值**：`16000`
- **说明**：音频采样率

#### `embedding_dim`
- **类型**：整数
- **默认值**：`192`
- **说明**：声纹嵌入向量维度（ECAPA-TDNN固定为192）

#### `min_samples`
- **类型**：整数
- **默认值**：`5`
- **说明**：每个说话人至少需要的音频样本数量

#### `adaptation_mode`
- **类型**：字符串
- **默认值**：`fine_tune`
- **说明**：适配模式：`fine_tune`(微调)、`feature_extract`(仅特征提取)

#### `skip_template_store`
- **类型**：布尔值
- **默认值**：`false`
- **说明**：是否跳过生成声纹模板文件

#### `batch_size`
- **类型**：整数
- **默认值**：`2`
- **说明**：批量大小

#### `epochs`
- **类型**：整数
- **默认值**：`3`
- **说明**：训练轮数

#### `learning_rate`
- **类型**：浮点数
- **默认值**：`1e-4`
- **说明**：学习率

#### `weight_decay`
- **类型**：浮点数
- **默认值**：`1e-4`
- **说明**：权重衰减

#### `optimizer`
- **类型**：字符串
- **默认值**：`adam`
- **说明**：优化器类型：`adam`/`sgd`/`adamw`

#### `scheduler`
- **类型**：字符串
- **默认值**：`cosine`
- **说明**：学习率调度器：`cosine`/`step`/`none`

#### `scheduler_step_size`
- **类型**：整数
- **默认值**：`5`
- **说明**：学习率衰减步数

#### `scheduler_gamma`
- **类型**：浮点数
- **默认值**：`0.1`
- **说明**：学习率衰减因子

#### `loss_function`
- **类型**：字符串
- **默认值**：`contrastive`
- **说明**：损失函数类型：`contrastive`/`triplet`/`softmax`

#### `margin`
- **类型**：浮点数
- **默认值**：`0.2`
- **说明**：对比损失/三元组损失的margin参数

#### `augment`
- **类型**：布尔值
- **默认值**：`true`
- **说明**：是否启用数据增强

#### `noise_level`
- **类型**：浮点数
- **默认值**：`0.05`
- **说明**：噪声增强的噪声水平

#### `speed_range`
- **类型**：列表
- **默认值**：`[0.9, 1.1]`
- **说明**：语速变化范围

#### `early_stopping`
- **类型**：布尔值
- **默认值**：`true`
- **说明**：是否启用早停机制

#### `early_stopping_patience`
- **类型**：整数
- **默认值**：`3`
- **说明**：早停耐心值

#### `early_stopping_delta`
- **类型**：浮点数
- **默认值**：`0.001`
- **说明**：早停阈值变化

### `validation`

#### `accuracy_target`
- **类型**：整数
- **默认值**：`96`
- **说明**：目标准确率(%)

#### `latency_target`
- **类型**：字符串
- **默认值**：`10ms`
- **说明**：目标延迟

#### `enabled`
- **类型**：布尔值
- **默认值**：`true`
- **说明**：是否启用验证

#### `eval_interval`
- **类型**：整数
- **默认值**：`1`
- **说明**：验证间隔（每N个epoch验证一次）

#### `save_best_model`
- **类型**：布尔值
- **默认值**：`true`
- **说明**：是否保存最佳模型

### `output`

#### `log_level`
- **类型**：字符串
- **默认值**：`info`
- **说明**：日志级别：`debug`/`info`/`warning`/`error`

#### 配置建议
- 当数据集较小时，建议将`freeze_layers`设为`true`，仅微调上层分类层
- 学习率建议设置为`1e-4`到`5e-4`之间
- 数据增强可提高模型泛化能力，但噪声水平不宜过高（建议0.05-0.1）

## 4. 配置文件使用方法

### 4.1 训练阶段

```bash
# 使用配置文件训练声纹模型
python train_speaker.py --config config/speaker_id_config.yaml

# 使用配置文件训练降噪模型

```

## 5. 最佳实践

1. **配置文件管理**
   - 为不同环境创建独立配置文件（如`config_development.yaml`、`config_production.yaml`）
   - 版本控制配置文件，记录配置变更历史

2. **参数调整建议**
   - 首先使用默认参数运行，观察效果后再进行调整
   - 调整参数时遵循"小步调整，逐步验证"的原则
   - 记录每次调整的参数和效果，建立优化档案

3. **性能与效果平衡**
   - 降噪强度过高可能导致语音失真，建议在25-30dB范围内调整
   - 声纹匹配阈值过低会增加误识别率，过高会降低识别率，建议在0.85-0.95范围内调整
   - 实时处理时，延迟和处理效果需要平衡，目标延迟建议设为25ms以内

## 6. 常见问题与解决方案

### 6.1 训练时内存不足
- **可能原因**：批量大小过大
- **解决方案**：减小`batch_size`参数

### 6.2 声纹识别准确率低
- **可能原因**：训练数据不足或质量差
- **解决方案**：增加训练数据或调整`augment`参数

### 6.3 降噪效果不佳
- **可能原因**：噪声类型不匹配
- **解决方案**：收集目标环境的噪声样本重新训练

### 6.4 实时处理延迟过高
- **可能原因**：并行线程数过多或配置不当
- **解决方案**：调整`num_threads`或禁用并行处理

### 6.5 系统稳定性差
- **可能原因**：资源优化配置不当
- **解决方案**：调整`memory_optimization`相关参数
